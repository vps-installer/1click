# Universal VPS Installer

**Язык:** [Русский](README.ru.md) | [English](README.md)

**РКН блокирует быстро и внезапно, но развернуть новую точку выхода можно ещё быстрее. Два протокола для обхода блокировок в одном скрипте! ;)**

Интерактивный установщик VPN-сервера на чистую **Ubuntu 24.04 LTS**.

Автоматизирует подготовку VPS, установку VPN-протоколов, настройку сетевой фильтрации и создание клиентских профилей.

## Что устанавливается и настраивается

- Системные обновления Ubuntu и необходимые утилиты.
- OpenSSH Server
- UFW
- Fail2ban
- fzf
- Xray (VLESS + XHTTP + REALITY)
- AmneziaWG
- Unbound
- nftables
- GeoBlock с автоматическим обновлением списков российских IP-адресов

**Всё управление — через удобное интерактивное меню командной строки.** Никаких дополнительных веб-панелей. После установки можно в любой момент вернуться к управлению сервером и клиентскими профилями через:

```bash
sudo vps-installer
```

При желании остаётся возможность работать с установленными компонентами напрямую через стандартные команды Linux.

## Для чего блокируется российский трафик через VPN

Некоторые приложения и системные службы продолжают обращаться к российским серверам даже при включённом VPN: для синхронизации, аналитики, уведомлений и других фоновых операций.

В результате российские сервисы могут увидеть IP-адрес зарубежного VPN-сервера.

Чтобы ограничить такие соединения, установщик настраивает фильтрацию на нескольких уровнях:

- **Xray:** блокировка российских доменов и IP-адресов через DNS, маршрутизацию и правила исходящих соединений.
- **AmneziaWG:** блокировка российских IPv4-подсетей через nftables, фильтрация DNS и ограничения маршрутизации.
- **Fail-closed:** запрещение трафика, не соответствующего разрешённым правилам.

**Цель — не допускать обращений к российским ресурсам через зарубежную точку выхода и уменьшить вероятность раскрытия её IP-адреса.**

При этом подключения пользователей из России к самому VPN-серверу не блокируются этими правилами.

Не панацея, но хоть что-то...

## Подключение клиентов по IPv4 и IPv6

Установщик поддерживает **входящие подключения клиентов по IPv4 и IPv6** для Xray и AmneziaWG. Это позволяет использовать публичный IPv6-адрес VPS как альтернативный адрес подключения к VPN, если сеть клиента поддерживает IPv6.

- **Автоматическое обнаружение IPv6:** установщик проверяет наличие назначенного серверу глобального IPv6-адреса и маршрута. Если подходящий адрес найден, при установке Xray или AmneziaWG (в том числе при повторном входе в соответствующий раздел) предлагается включить входящие IPv6-подключения. IPv6 включается только с подтверждения пользователя.
- **Xray:** для VLESS + XHTTP + REALITY создаётся отдельный IPv6-вход на TCP-порту 443 с теми же настройками и клиентскими идентификаторами, что и у IPv4. Существующий IPv4-вход сохраняется. Проверяются настройки конфигурации, работа службы и доступность локального IPv6 TCP-сокета; при ошибке активации исходная конфигурация восстанавливается.
- **AmneziaWG:** сервер может принимать клиентские подключения к своему UDP-порту через публичный IPv6-адрес. Клиенту предлагается вариант конфигурации с IPv6-адресом в `Endpoint`; ключи и остальные параметры остаются прежними, сохранённый `.conf` не переписывается. Фактическое соединение необходимо подтвердить внешним клиентом.
- **Управление профилями:** при создании и просмотре профиля можно выбрать адрес подключения **IPv4** или **IPv6**. Для IPv6 используются существующие клиентские ключи/UUID — отдельного клиента создавать не требуется. VLESS-ссылки, конфигурации и QR-коды формируются с выбранным адресом.
- **Проверки:** перед включением IPv6 установщик проверяет настройки UFW и соответствующий входящий порт. IPv6-вариант профиля не выдаётся, если IPv6-вход не включён или адрес больше не назначен VPS.

**Важно: IPv6 здесь используется для входа клиента на VPN-сервер, а не для выхода VPN-трафика в интернет по IPv6.** Xray сохраняет IPv4-only политику исходящих соединений, а AmneziaWG не включает пересылку IPv6 через туннель и блокирует такой трафик правилами GeoBlock. Фильтрация российских IPv4-сетей и остальные ограничения сохраняются.

Для работы IPv6-подключения нужен доступный IPv6 как на VPS, так и в сети клиента. Это не гарантирует отсутствия обхода VPN или утечек IPv6 на клиентском устройстве: параметры маршрутизации и поведение Android/клиентского VPN-приложения необходимо проверять отдельно.

## Управление клиентскими профилями

Через интерактивное меню можно:

- Создавать отдельные профили Xray и AmneziaWG.
- Просматривать существующие профили без изменения ключей.
- Получать VLESS-ссылки и конфигурации AmneziaWG.
- Отображать QR-коды непосредственно в SSH-терминале.
- Сохранять QR-коды в PNG.
- Получить конфигурацию в формате yaml (SSClash/Mihomo)

## Автоматическое обслуживание

**Обновления VPN-компонентов:** Xray Core обновляется вручную через меню Xray с резервным копированием и проверкой конфигурации, без замены GeoData и ключей. Пакеты AmneziaWG продолжают обновляться штатным еженедельным APT; после обновления проверяются модуль текущего ядра, интерфейс, DNS-служба и GeoBlock. Автоматическая перезагрузка по умолчанию отключена; при её включении выполняются дополнительные проверки. Перезагрузки вне установщика этими проверками не защищены.


Дополнительное меню **Automatic maintenance** управляет обновлениями GeoIP/GeoSite Xray, существующим таймером GeoBlock AmneziaWG, ежедневными обновлениями безопасности Ubuntu и еженедельным APT, почтовыми уведомлениями через msmtp, а также статусами и журналами таймеров systemd. Адрес отправителя одновременно используется как SMTP-логин; адрес получателя задаётся отдельно. Автоматическая перезагрузка по умолчанию отключена.

## Установка

На чистом VPS с Ubuntu 24.04 LTS выполнить под `root`:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/vps-installer/1click/main/install.sh)"
```

После первоначальной установки подключиться по SSH под созданным администратором. Для управления профилями и повторного запуска меню:

```bash
sudo vps-installer
```
